# Ordering.co Dashboard

Open your Dashboard locally with your Ordering project and make your first change with a coding agent.

## 1. Paste this into your coding agent

```text
Set up https://github.com/Ordering-co/ordering-dashboard.git locally. Read setup.md, reuse this checkout if it exists, help me confirm my Ordering project, then open the Dashboard and guide me through one simple visible edit.
```

## 2. Confirm your project

Follow the agent's prompts to confirm your Ordering project. If it cannot detect one, give it the slug of a project you are authorized to use. If you need to sign in to the Dashboard, use your normal account.

## 3. Open your Dashboard

Open the local link the agent provides and check the project shown on the login screen. Ask for a small visible change and watch it update.

Requires a coding agent, Node.js, pnpm, and an Ordering project you are authorized to use.
