# Agent guidance

Read CLAUDE.md and setup.md before editing. Configure development and optional services with your own authorized project and accounts. Changes to settings must follow docs/SETTINGS.md and docs/SETTINGS_DISTRIBUTION.md. Preserve the in-tree controllers/UI, dependency lockfile and third-party notices. Never commit credentials or local tenant secrets.

Run lint, build, i18n generation/completeness and relevant tests. Keep Settings in its existing hub; preserve addon visibility and route/palette indexing. Publication, deploy, live sync and authenticated operations require the repository owner's authorization.
